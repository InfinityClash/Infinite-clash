# Infinite Clash ⚔️

An autonomous AI anime battle simulator featuring **235 fighters**, simultaneous team battles, unique **Captain Effects**, and **no plot armor**.

## 🔥 What is Infinite Clash?

Infinite Clash is an autonomous battle simulation where **the AI controls every fighter**.

You are the **spectator and roster manager** — you never control an individual fighter.

Every established fighter has their own abilities, strengths, weaknesses, personality, tactics, and limitations based on their Lorebook profile.

The outcome is determined by the battle itself: **matchups, abilities, tactics, teamwork, environment, timing, and chance**.

There are no predetermined winners.

## ⚔️ Battle Modes

- **2v2** — 4 fighters battle simultaneously
- **3v3** — 6 fighters battle simultaneously
- **4v4** — 8 fighters battle simultaneously

All fighters participate at the same time.

### 👑 Captain System

Every fighter has a unique **Captain Effect** based on their Lorebook profile.

After your team is created, you choose your Captain.

The opposing AI independently selects its own Captain.

Captain Effects influence team coordination, tactics, behavior, and other aspects of the battle.

## 🎭 Fighter Roles

Fighters can be classified as:

- **COMBAT** — frontline fighters and attackers
- **HYBRID** — fighters capable of multiple battlefield roles
- **SUPPORT** — healing, buffs, utility, control, and other support abilities

Support fighters can still fight directly when necessary.

## 🏆 Rank System

Fighters use the following combat ranks:

**F → E → D → C → B → A → S**

Extremely rare fighters can possess the **ANOMALY** classification.

Rank represents general combat capability.

**Rank is not the same as rarity.**

A lower-ranked fighter can defeat a higher-ranked fighter depending on the matchup, abilities, tactics, environment, timing, and circumstances.

## 🚀 Installation

### Recommended — Complete Tavo Import

Download:

**`Tavo_Infinite Clash_1v50A.json`**

Then in Tavo:

1. Open **Characters**
2. Select **Create**
3. Choose **JSON Import**
4. Select the downloaded `.json` file
5. Import it
6. Choose **Save as** if Infinite Clash already exists
7. Open the imported character
8. Start a new chat

The character and its **Infinite Clash — Fighter Database** Lorebook are included in the import.

### Greeting Only

If you already have your own Infinite Clash character and only need the latest Greeting, use:

**`Infinite-Clash-Greeting.html`**

## 🤖 Autonomous AI

Infinite Clash is designed so that the AI independently controls:

- Movement
- Attacks
- Defense
- Abilities
- Transformations
- Teamwork
- Target selection
- Tactical decisions
- Reactions
- Dialogue
- Retreats
- Adaptation
- Captain Effect usage

The user does **not** control fighters during battles.

## 📚 Lorebook

The fighter database contains the profiles used by Infinite Clash during battles.

Only the profiles of the fighters participating in the current battle are supplied to the battle AI, keeping the battle context manageable while preserving detailed fighter information.
